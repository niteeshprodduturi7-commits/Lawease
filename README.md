# LawEase – AI-Powered Legal Assistance Platform

## Overview

LawEase is an AI-powered legal assistance platform designed to help users understand legal rights, laws, regulations, and legal procedures through an interactive chatbot and document analysis system.

## Features

* AI Legal Chatbot for legal guidance
* Legal document analysis and summarization
* Multi-language support
* User authentication and profile management
* Legal information and awareness modules
* Responsive user interface

## Technology Stack

### Frontend

* React.js
* Bootstrap
* HTML
* CSS

### Backend

* Node.js
* Express.js
* Python (Flask)

### Database

* MongoDB

### AI & NLP

* Groq LLM API
* OCR-based document processing

## Project Structure

* Frontend – User interface and chatbot integration
* Backend – APIs, authentication, and document processing
* AI Modules – Legal document summarization and analysis

## Future Enhancements

* Lawyer appointment booking
* Legal case tracking
* Advanced document intelligence
* Voice-enabled legal assistant
